🖨️ Imprimir por repartidora

Seleccioná una repartidora o imprimí todas juntas.

    🗑️ ¿Borrar todos los pedidos?

    Se eliminarán todos los pedidos. Precios y stock no se borran. Esta acción no se puede deshacer.

    ⚙️ Configurar Firebase

    1
    Crear proyecto en Firebase (gratis)

    Abrí console.firebase.google.com → "Crear proyecto" → nombre (ej: mis-pastas) → desactivar Analytics.

    2
    Activar Realtime Database

    Menú izquierdo: Build → Realtime Database → Create Database. Elegí ubicación → Start in test mode → Enable.

    3
    Activar autenticación

    Menú: Build → Authentication → Get started → Email/Password → Enable → Save.

    4
    Obtener configuración

    Project Overview ⚙️ → Project settings → General → Your apps → ícono </> → Registrar app → copiar el objeto firebaseConfig.

    5
    Pegá la config acá:
    ❌ Config inválida. Pegá el objeto firebaseConfig completo.

    🔒 Reglas de seguridad para Firebase

    Copiá estas reglas y pegálas en: Firebase → Realtime Database → Rules → Publish.
    Esto garantiza que solo vos podés leer y escribir tus datos.

    { "rules": { "usuarios": { "$uid": { ".read": "auth != null && auth.uid === $uid", ".write": "auth != null && auth.uid === $uid" } } } }

    Con estas reglas: solo usuarios autenticados pueden acceder, y cada usuario solo puede ver sus propios datos.
